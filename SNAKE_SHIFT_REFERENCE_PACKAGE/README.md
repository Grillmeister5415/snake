# SNAKE//SHIFT — Reference Package

This package contains the complete game-building prompt and seventeen original concept reference images for the SNAKE//SHIFT browser game.

The earlier conversation contained visual-search reference prompts, but no downloadable image files. These original concept images were created for this package. They are visual references, not required runtime assets. The user-supplied [Tennis app](https://tennis.sixfingerpunch.com/) informed the new synthwave night-court direction: minimal black-and-white play can erupt into a huge 3D perspective arena with a checkerboard floor, horizon sun, violet sky, and neon frame. The new Snake art is original and does not copy the app's assets. Five additional rooms use the attached POV image as framing reference: psychedelic glassflower trip, Soviet-inspired tank hangar, voxel mushroom land, original storybook sky castle, and abyssal cathedral. The storybook scene avoids recognizable franchise characters.

## Core design constraint

The game may shift between flat 2D visuals and a fully rendered 3D room. In 3D mode the snake itself appears as a modeled object inside the room, moving over a gridded floor; occasionally the camera shifts to the snake's head for a first-person passage. The simulation remains the same flat rectangular grid, with the same four-direction controls, growth, speed progression, and collision rules.

The art direction is intended to feel extreme and explosive through color, scale, density, and hard scene changes. It avoids rapid full-screen strobing and includes reduced-flash and reduced-motion settings.
