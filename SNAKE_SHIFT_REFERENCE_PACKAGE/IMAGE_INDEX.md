The 3D-room reference is the key dimensional-shift example: the snake appears inside real 3D architecture, while the board itself remains a flat gridded plane. The POV reference shows an occasional head-level view; keep the same grid, controls, and collisions. The five newest images add original 3D rooms in psychedelic, Soviet tank hangar, voxel mushroom, whimsical storybook, and underwater cathedral themes. The storybook concept is original and does not depict recognizable franchise characters.
